# EduNova LMS V1.0 Stable

EduNova adalah Learning Management System (LMS) berbasis web yang dirancang untuk mendukung digitalisasi pembelajaran sekolah.

## Release Information

Version:
v1.0.0

Release Type:
Production Stable Release

## Main Features

✅ Student Management  
✅ Teacher Management  
✅ Course Management  
✅ Classroom Management  
✅ Assignment System  
✅ Quiz & Assessment  
✅ Attendance Management  
✅ Dashboard Analytics  
✅ Docker Production Deployment  
✅ Backup & Restore System  

## Technology Stack

- Laravel
- React + TypeScript
- Tailwind CSS
- PostgreSQL
- Redis
- Docker
- Nginx

## Deployment

Supported deployment:

- VPS Linux
- Docker Environment
- School Server
