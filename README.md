# EduNova LMS

## EduNova V1.0 Stable

EduNova adalah Learning Management System (LMS) berbasis web yang dirancang untuk membantu sekolah melakukan transformasi digital pembelajaran.

Platform ini menyediakan pengelolaan siswa, guru, kelas, materi pembelajaran, tugas, quiz, absensi, dan monitoring akademik.


# Features

## Student Module

- Dashboard siswa
- Mengakses kelas
- Melihat materi
- Mengirim tugas
- Mengikuti quiz
- Melihat nilai


## Teacher Module

- Dashboard guru
- Mengelola kelas
- Upload materi
- Membuat tugas
- Membuat quiz
- Monitoring aktivitas siswa


## Academic Management

- Data siswa
- Data guru
- Kelas
- Mata pelajaran
- Absensi
- Penilaian
