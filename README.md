## About EduNova

EduNova adalah Learning Management System (LMS) berbasis web yang dirancang untuk membantu sekolah melakukan transformasi digital pembelajaran.

Platform ini menyediakan sistem pengelolaan siswa, guru, kelas, materi pembelajaran, tugas, ujian, absensi, dan monitoring aktivitas akademik.


# Features

## Student Module

- Dashboard siswa
- Akses kelas
- Materi pembelajaran
- Pengumpulan tugas
- Mengikuti quiz
- Melihat nilai
- Riwayat aktivitas


## Teacher Module

- Dashboard guru
- Manajemen kelas
- Upload materi
- Membuat tugas
- Membuat quiz
- Monitoring siswa

- Data siswa
- Data guru
- Mata pelajaran

## Assessment System

- Penilaian otomatis
- Rekap nilai
- Monitoring hasil belajar
